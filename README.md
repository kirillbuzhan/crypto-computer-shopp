# Криптография и теория информации — учебный сайт

Интерактивная лаборатория и справочные статьи по курсу криптографии и теории информации:

- **Лаборатория** (`/lab`) — система передачи «источник → кодер → декодер → приёмник» с пошаговыми разборами:
  переворачивание текста, коды Хаффмана и Шеннона–Фано, коды Хэмминга и Адамара (с моделированием ошибок),
  шифр Эль-Гамаля (с генерацией больших простых по критерию Поклингтона), а также примеры по алгебре:
  моноиды, диофантовы уравнения, сравнения, вычеты.
- **Теория** (`/theory`) — 12 статей с определениями, доказательствами, разобранными примерами и вопросами для самопроверки.
- **Справочник** (`/reference`) — глоссарий с поиском, сводка формул, обозначения, литература.

Сайт не использует внешние CDN, базы данных и не хранит пользовательские данные: каждый запрос обрабатывается независимо,
поэтому сервер можно запускать в нескольких процессах и перезапускать в любой момент.

## Локальный запуск

Нужен Python 3.12+.

```bash
python launcher.py            # установит зависимости, запустит сервер и откроет браузер
```

или вручную:

```bash
pip install -r requirements.txt
uvicorn main:app --reload     # http://127.0.0.1:8000
```

Тесты:

```bash
pip install -r requirements-dev.txt
pytest
```

## Развёртывание

### Docker (рекомендуется)

```bash
cp .env.example .env          # при необходимости поправить настройки
docker compose up -d --build  # сайт на 127.0.0.1:8000
```

Контейнер работает от непривилегированного пользователя, имеет healthcheck (`/healthz`) и перезапускается автоматически.
Наружу порт открыт только на `127.0.0.1` — публикует сайт обратный прокси (nginx), он же отвечает за HTTPS.

### Без Docker (systemd)

```bash
sudo mkdir -p /opt/crypto-lab && sudo cp -r . /opt/crypto-lab
cd /opt/crypto-lab
sudo python3 -m venv .venv && sudo .venv/bin/pip install -r requirements.txt
sudo cp deploy/crypto-lab.service /etc/systemd/system/
sudo systemctl daemon-reload && sudo systemctl enable --now crypto-lab
```

### nginx

Пример — [deploy/nginx.conf](deploy/nginx.conf). Поддерживаются два варианта:

| Вариант | Адрес | Что настроить |
|---|---|---|
| Отдельный (под)домен | `https://crypto.university.ru/` | ничего |
| Подкаталог сайта | `https://university.ru/crypto-lab/` | `ROOT_PATH=/crypto-lab` в `.env` |

В варианте с подкаталогом прокси может как передавать путь целиком (`/crypto-lab/theory`), так и отрезать префикс (`/theory`) —
приложение корректно работает в обоих случаях.

## Настройки

Все параметры задаются переменными окружения (файл `.env`), см. [.env.example](.env.example):

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `ROOT_PATH` | пусто | префикс адреса при публикации в подкаталоге |
| `SITE_TITLE` | Криптография и теория информации | название в шапке и заголовках |
| `SITE_ORGANIZATION` | пусто | кафедра / университет (подвал, «О проекте») |
| `SITE_AUTHORS` | пусто | авторы |
| `SITE_CONTACT_EMAIL` | пусто | контактный адрес в подвале |
| `MAX_MESSAGE_LENGTH` | 500 | максимальная длина сообщения в лаборатории |
| `MAX_ELGAMAL_MESSAGE_LENGTH` | 200 | то же для шифра Эль-Гамаля (каждый символ — отдельное шифрование) |
| `WEB_CONCURRENCY` | 2 | число процессов сервера |
| `STATIC_VERSION` | 16 | меняйте при обновлении CSS/JS, чтобы браузеры не держали старые файлы |

## Структура проекта

```
main.py                 страницы сайта и JSON API лаборатории
config.py               настройки из переменных окружения
content/
  topics.py             каталог статей: порядок, разделы, связь с лабораторией
  reference.py          глоссарий, формулы, обозначения, литература
transmission/           источник, кодер, декодер, приёмник и алгоритмы кодирования/шифрования
algebra/                теория чисел, моноиды, генерация простых (pocklington.py)
web/templates/          шаблоны: base.html (каркас), lab.html, theory/*.html — статьи
web/static/             site.css (сайт), style.css + script.js (лаборатория), common.js (общее)
tests/                  тесты алгоритмов, примеров из статей и страниц
deploy/                 примеры nginx и systemd
```

### Как добавить статью

1. Добавить `Topic(...)` в `content/topics.py` (slug, название, краткое описание, раздел, ключ алгоритма лаборатории).
2. Создать `web/templates/theory/<slug>.html`, унаследовав `theory_base.html` и заполнив блок `article`.
3. Формулы писать простым текстом: `<span class="f">a^(n−1) ≡ 1 (mod n)</span>` (строчная) или
   `<div class="f-block">…</div>` (выключная) — степени, индексы (`x_1`, `H_(2n)`) и курсив переменных
   оформит скрипт. Для блоков есть классы `box definition | theorem | example | warning | lab`.
4. Запустить `pytest` — тест проверит, что все статьи открываются.

## API лаборатории

| Метод | Адрес | Назначение |
|---|---|---|
| POST | `/transmit` | передать сообщение выбранным алгоритмом (`algorithm`, `message`, параметры алгоритма) |
| POST | `/elgamal/keys` | ключи Эль-Гамаля: `{message}` — учебные, `{bits}` — большое простое с сертификатом Поклингтона |
| POST | `/monoid`, `/diophantine`, `/congruences`, `/residues` | пошаговые разборы учебных примеров |
| GET | `/healthz` | проверка работоспособности |

Большие числа в ответах передаются строками, чтобы JavaScript не терял точность. Сертификат простоты для большого `p`
возвращается клиенту и присылается обратно при шифровании; сервер перепроверяет его и ничего не хранит.
